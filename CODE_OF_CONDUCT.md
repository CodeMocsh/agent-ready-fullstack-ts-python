# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. That document is the code of conduct; this file says who enforces it and how you reach
them.

Restating the text here would mean maintaining a second copy of it, and a copy drifts. Read it
at the link.

## Reporting

Report unacceptable behaviour through GitHub's **private vulnerability reporting** on this
repository — the *Security* tab, then *Report a vulnerability*. It is the private channel this
project has, and it reaches the maintainers and nobody else. Say what happened and when.

Every report is reviewed. The maintainers respect the privacy and the security of whoever
reports, and will say what they intend to do before they do it.

## Scope

This applies wherever someone represents the project: issues, pull requests, discussions,
commit messages, and any public space where you are speaking for it.

The enforcement ladder — correction, warning, temporary ban, permanent ban — is the one in the
Contributor Covenant, and the maintainers follow it.
